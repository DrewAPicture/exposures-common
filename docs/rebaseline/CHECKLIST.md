# Rebaseline Audit Checklist

Use this checklist whenever meaningful shared-surface changes land in `exposures-phone` and/or `exposures-watch` (for example after Phases 8/9).

## 1) Prepare

- Confirm both sibling repos are present locally as `../phone` and `../watch`.
- Make sure both repos are updated to the intended comparison points (`main`, feature branch, or specific commits).
- Choose an output path for the report (default is generated by script under `docs/rebaseline/`).

## 2) Run automated audit

- Run:
  - `./scripts/rebaseline-audit.sh`
- Optional custom output path:
  - `./scripts/rebaseline-audit.sh --output docs/rebaseline/report-YYYY-MM-DD.md`

## 3) Review results

- Verify `core-datalayer` contract files parity:
  - `DataLayerPaths.kt`
  - `DataLayerJson.kt`
  - `dto/Dtos.kt`
  - `mapper/DtoMappers.kt`
  - `DataLayerGateway.kt`
  - `DataLayerClient.kt`
- Verify `core-model` high-risk files parity:
  - `CameraBody.kt`, `Lens.kt`, `FilmRoll.kt`, `Exposure.kt`, `ShutterSpeed.kt`, `Zone.kt`
- Review database-common candidates for extraction (non-blocking):
  - `Converters.kt`
  - `mapper/Mappers.kt`
  - entities that might be safely shared

## 4) Make extraction decisions

- Mark each mismatch as one of:
  - **Intentional divergence** (document why)
  - **Should converge before extraction**
  - **Out of scope for shared modules**
- Update extraction map in planning docs accordingly.

## 5) Contract/versioning follow-through

- If DTO/path/model contracts changed:
  - Update snapshot tests/scaffolding in `core-datalayer` tests.
  - Update compatibility notes in `docs/CONTRACT_COMPATIBILITY.md`.
  - Determine version bump (`patch`/`minor`/`major`) for `exposures-common`.
- Record any required coordinated rollout steps for phone/watch.

## 6) Sign-off gate before consumer replacement

- Rebaseline report exists and is linked in the work item/PR.
- Include/exclude decisions are explicit.
- Compatibility and versioning actions are captured.
- Only then proceed with replacing/removing duplicated modules in consumer repos.
